# 4.2 Media Library

> **Parent:** [requirements.md](../requirements.md)

---

Teams have a shared media library where members can upload images, videos, audio files, GIFs, and
documents. Each file can be up to 50 MB. Upload is a request/upload/confirm flow: the API creates
a pending upload, the browser uploads bytes either directly to R2 or through the local API upload
proxy on localhost, and confirmation verifies the stored object before the asset becomes visible.

When a file is confirmed, the system automatically:

- Generates a thumbnail
- Assigns an AI-generated title, description, and tags
- Creates a vector embedding for semantic search (so users can search by concept, not just keywords)
- Classifies the content category and emotional tone

Users can also manually tag assets, organise them into collections, and search using both keywords
and natural language. Assets are isolated per team — a user can only see media belonging to teams
they are a member of.

When an asset is deleted, it is soft-deleted (hidden from the UI but retained in storage). It is
permanently removed after **1-2 days** (default: **48 hours**).
